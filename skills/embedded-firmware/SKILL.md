## 何时加载
任务涉及 MCU/RTOS 固件、板级 bring-up、外设驱动、总线通信故障、功耗发热、EMC、产线测试或 OTA。纯 App/服务端不加载；跨软硬边界（App↔BLE↔固件）时与 android-app 联用。

## 需求到软硬件分解
1. 功能 → 传感器/执行器清单：量程、精度、采样率、接口（I2C/SPI/UART/ADC/GPIO）。
2. 电源预算：逐器件列电压/电流/占空比，`I_avg = Σ(I_i × d_i)`；续航 `h = 容量mAh / I_avg`，留 30% 余量。
3. 时序约束：控制周期、响应延迟、启动时间 → 反推主频、DMA 通道与中断预算。
4. 选型取舍：MCU 看 Flash/RAM/外设/封装/温度等级/供货；通信按距离-速率-功耗-组网选（BLE/WiFi/LoRa/CAN/RS485）。
5. BOM 与替代料：关键料备 pin-to-pin 替代，标注生命周期与最小起订量。
6. 先定接口契约（引脚表、寄存器映射、协议帧格式），再画板写码。

## 固件骨架
- 分层：`hal/`(可 mock) → `drivers/`(器件) → `app/`(状态机/业务) → `platform/`(启动、时钟、OS)。
- 中断：短小，不做浮点/阻塞/打印；按实时性分级（控制 > 通信 > 日志）；共享数据用 `volatile` + 临界区或队列。
- DMA：SPI/UART/ADC 大块传输走 DMA，处理 `TC/HT/ERR` 回调；环形缓冲区分读写指针防撕裂。
- 看门狗：只在主循环健康检查通过处喂，不在中断/定时器盲喂；分阶段打点，复位后记录原因与阶段号。
- 低功耗：空闲进 Sleep/Stop，外设按需上电；唤醒源与中断使能逐项核对；实测休眠电流。
- 状态机：显式 `enum State` + 事件表，禁止散落 if 嵌套；每状态定义超时与错误出口。
- 时间基准：统一 tick 源，超时用单调时钟；中断里不做长延时。
- RTOS：任务优先级按截止期排；栈大小按实测高水位 +50%；共享资源用互斥量并开优先级继承防反转；队列长度按峰值留余量。

## 总线与协议排障
- I2C：`i2cdetect -y <bus>` 扫地址（7 位地址左移一位）；无应答查供电/上拉（典型 4.7k）/地址跳线；从机不支持时钟拉伸则降到 100kHz；SDA 被拉低挂死时发 9 个 SCL 时钟解锁。
- SPI：核对 CPOL/CPHA 四模式、帧内片选保持、时钟不超从机上限；MISO 常高/常低多为片选或模式错。
- UART：波特率误差 <3%（核对晶振与分频）；TTL 与 RS232 电平不能直连；TX/RX 交叉；先自发自收再对接。
- CAN：两端各 120Ω 终端（断电测总线约 60Ω）；位定时采样点 75%~87.5%；`candump can0` 看错误帧，查终端/线序/共地。
- BLE：连接参数（interval 7.5ms~4s、latency、timeout）按功耗与延迟取舍；MTU 协商到 247 才高效；配对用 LE Secure Connections；丢包先看 RSSI 与信道干扰。

## Bring-up 顺序与验收信号
1. 电源：各轨电压/纹波达标，上电时序符合 datasheet（示波器双通道看）。
2. 时钟与复位：晶振起振，释放复位、启动引脚电平正确。
3. 调试口：SWD/JTAG 能连上、读到 ID、能单步。
4. 串口日志：能打印启动 banner 与版本号。
5. 通信总线：扫描/回环验证物理层。
6. 传感器：读 ID 寄存器（WHO_AM_I）匹配后再读原始数据。
7. 业务逻辑：闭环控制/状态机跑通。
8. OTA：升级、校验、回滚各验证一次。
每步不过不跳级，记录实测波形与数据。

## 仪器与工具
- 万用表：电压/通断/电流；测电流须串入回路或用功耗分析仪，注意量程。
- 示波器：看纹波（20MHz 带宽限制 + 短地线弹簧）、上电时序、总线波形、中断抖动。
- 逻辑分析仪：解码 I2C/SPI/UART/CAN（PulseView 或 `sigrok-cli`），从上电全程抓首个错误帧。
- 调试与串口：`openocd -f interface/stlink.cfg -f target/stm32f4x.cfg` 后 GDB `target remote :3333` 读寄存器/内存；串口 `python -m serial.tools.miniterm COM<port> 115200`，日志带时间戳与模块前缀。

## 电源与热
- 纹波：开关电源输出纹波目标 < 输出电压 1%；LDO 输入输出加 1uF+100nF 去耦并靠近引脚。
- 上电时序：多轨系统核对上电/掉电顺序与使能，防倒灌；接口加 TVS/ESD 保护。
- 压降：大电流路径按线宽铜厚算压降；电池供电关注截止电压与低压复位阈值。
- 温升：`P = I²R` 估算并实测壳温；功率器件留 ≥20% 余量，靠散热焊盘/过孔/铺铜。
- 电池：充电 IC 恒流/恒压/截止参数、过放保护、NTC 测温；定义低电量策略与安全关机。
- 浪涌：上电加软启动/限流，测启动电流峰值，防止电池保护板误触发或适配器掉压。

## 安全与可靠性
- 安全启动：固件验签（RSA/ECDSA）、防回滚（版本号 + 一次性计数器）、量产锁死调试口。
- 密钥：存 MCU 安全区/一次性烧录区，不进源码与日志；产线注入并登记。
- 掉电保护：Flash 用双区或日志式写入，写前擦、写后校验，掉电后能恢复默认；关注擦写寿命（10 万次量级）与磨损均衡。
- 喂狗边界：所有任务心跳正常后才喂；长操作分段喂狗。
- EMC：接口加共模电感/TVS，时钟线远离接口，地平面完整；辐射超标先查线缆与晶振。

## 产线与版本
- 版本号 `MAJOR.MINOR.PATCH+BUILD`，固件内嵌 git hash 与编译时间，串口可查。
- 测试夹具：上电自检、电流、通信、传感器读数、射频功率、按键/显示逐项判定，输出 PASS/FAIL 与序列号。
- 校准：传感器零点/增益、射频频偏、电池曲线；校准系数写入后回读校验。
- 序列号唯一可追溯（批次/日期/工位），与云端登记对账。
- OTA 回滚：A/B 分区或双 bank，校验失败自动回退；升级前查电量与网络，断电可恢复。
